# 合同文件命名规则（叶律师 2026-11-18 定）

## 格式

```
客户-合同名（标的/对方）（客户标记）-状态-版本-YYYYMMDD.扩展名
```

例：`飞力达-房屋租赁合同（西塔2F02）（双审）-审核回复-V2-20251113.docx`

## 各段规则

| 段 | 规则 | 例 |
|---|---|---|
| 客户 | 与 `00.已经处理/` 下文件夹同名，一律简体 | `飞力达`（不写 飛力達）、`珍珍`、`李幸庆` |
| 合同名 | 照合同原文写，不改不简写（地名、编号、文种都保留）：合同／协议／法律意见书／备忘录／函。≤30 字 | `深圳市房屋租赁合同书`、`法律意见书`、`购销合同` |
| （标的/对方） | 全角括号，只写有区分意义的：标的、楼栋、对方公司简称 | `（西塔2F02）`、`（标准版）`、`（易德龙Coso）` |
| 状态 | 固定词表，见下 | `审核回复` |
| 标记 | 客户给的标记，用括号紧跟合同名后面，如实保留 | `（双审）`、`（批注）` |
| 版本 | `V1` `V2`…，只在原文本身有版本号或同状态多稿时写，单稿不写 | `V2` |
| 日期 | `YYYYMMDD` 8 位，取该件出具/交付日；查不出就不写，不猜 | `20251113` |

分隔符统一半角 `-`。段内不用 `-`、不用空格。

## 状态词表（只许用这些）

`拟定稿-P`｜`草稿`｜`修订版`｜`审核回复`｜`批注版`｜`定稿`｜`签署版`

- 同一份合同连改多轮、状态不变 → 递增版本：`审核回复V1`、`V2`、`V3`
- 状态变了 → 版本重新算（`定稿`、`签署版` 不带 V 号）
- 「最终版」「最后版」「最新版」「修改搞」一律不用，该是 `定稿` 就是 `定稿`

## 客户与主体的对应关系

- 客户名 = 委托我们的那个人/公司，不一定等于合同当事人
- 例：`友晟纸业`、`煜晟旺`、`大承` 都是李幸庆的 → 第一段统一写 `李幸庆`
- 例：`深圳齐心集团` 是坪山实验采购项目的相对方 → 第一段写 `坪山实验`

## 禁止出现

`_副本`、`(1)`、`【】`、`最终版`、`最后版`、`最新`、繁体字（客户名）、
段内空格、下划线、`修改搞` 这类错字。

重复件不靠文件名区分：先按内容哈希比对，真重复只留一份，不是重复的才加 `-2`。

## 工具

```bash
cd ~/cc/合同归档工具
python3 rename.py "<文件夹>"          # 出台账，不动文件
python3 rename.py "<文件夹>" --apply  # 真改名（重名自动加 -2，从不覆盖）
```

台账存在 `改名台账/日期.csv`，含「原文件名／新文件名／客户／状态／版本／日期／识别依据」，可反查。
