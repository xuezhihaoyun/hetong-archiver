# 归档规则（客户怎么判、模板和「其他」怎么归）

## 判定顺序（代码已实现，不用手工绕过）

| 顺位 | 依据 | 置信 | 自动移动 |
|---|---|---|---|
| 1 | **合同当事人主体**：抽甲方／乙方／出租方／承租方／委托方／受托方／发包方／承包方／买方／卖方／用人单位／劳动者等标签后的名称，比对客户别名 | 高 | 是 |
| 2 | **文件名 / 所在子文件夹名**出现客户别名 | 高 | 是 |
| 3 | **正文关键词**（别名 ≥3 字才算，防「上海华加」误命中「海华」） | 中 | 是 |
| 4 | **固定规则**（`file_rules`，人工确认过） | 高 | 是 |
| 5 | **空白模板**：抽不出主体 + 文件名含「模板/标准版/甲方版」或正文 ≥3 处 `____` → `其他/模板库` | — | 是 |
| 6 | 都不中 → 待定，**留在 `中转` 原地** | — | 否 |

`weak: true` 的别名（如「齐心」）只做提示，不触发自动移动；两个当事人分属不同客户时判为冲突，也进待定。

## 主体抽取怎么做的

- `.docx`：解 zip 读 `word/document.xml` + `docProps`
- `.doc`：系统 `textutil -convert txt`
- `.pdf`：`mdls` 取 Spotlight 文本（取不到就当无主体）
- 名称清洗：去排版空格、去「（以下简称…）」、未闭合括号截断、遇「统一社会信用代码／地址／法定代表人／联系人／电话／税号」停
- 组织校验：必须以「公司/学校/幼儿园/小学/中学/大学/社区/居委会/工作站/医院/银行/事务所/集团/研究院/中心/委员会/基金/协会/分行/分公司/办事处…」结尾，否则丢弃（防「学校参加活动的每个班」这类误抽）

## 四个去向

| 去向 | 什么件 |
|---|---|
| `<客户文件夹>` | 有主体、能确定客户 |
| `其他/模板库` | 空白模板（补全后可复用） |
| `其他` | 非合同件（调研报告等）、重复件、无主体又无归属的杂件 |
| 留在 `中转` | 判不出或需人工确认——**不为了清空目录硬塞别处** |

## 重复件怎么处理

先按内容（MD5）比对：

- 与目标目录已有文件**完全一致** → 不新增副本，报出来让人决定删/留/挪 `其他`
- 只是重名、内容不同 → 文件名加 `-2`，两份都留

## 例外与豁免（已拍板）

- **廉洁承诺书和告知书**：不属于任何客户，留在 `中转` 不动，不归「其他」
- **投研报告类 PDF**（如《珠海蓝图…一级市场投资调研报告》）：不是合同审查交付物，进 `其他`
- **重复件**：进 `其他`，文件名标注「（重复件，同 XX 目录）」

## 三条硬红线

1. 从不删除文件；重名不覆盖
2. 演练是默认模式，`--apply` 才动文件
3. 客户归属有歧义 → 问人，不猜
