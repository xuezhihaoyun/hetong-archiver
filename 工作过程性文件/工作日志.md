# 口径卡（本项目"仍有效"规则，不超过 20 条；完整出处见流水区节号）

1. 三个区：根目录＝待审｜`中转`＝审完待归档｜`00.已经处理/<客户>/`＝归档。（S1）
2. 命名格式：`客户-合同名（标的/对方）（客户标记）-状态-版本-YYYYMMDD`。（S3）
3. 合同名照原文，一个字不改不漏；`深圳市房屋租赁合同书` 不缩写。（S6）
4. 状态七词：`拟定稿-P`｜`草稿`｜`修订版`｜`审核回复`｜`批注版`｜`定稿`｜`签署版`；「最终版/最后版/修改搞」禁用。（S3）
5. 「双审」是客户给的标记，放合同名后用括号：`房屋租赁合同（双审）`。（S5）
6. 日期取件上能认出的日期，查不出**不写、不猜**；叶律师确认不用合同签订日替代。（S7）
7. 客户＝委托我们的人，不等于合同当事人。（S4）
8. 关联主体并一客户：友晟纸业/煜晟旺/大承 → 李幸庆；珍珍宠物 → 珍珍。（S7）
9. 上海华加两份物流件（反商业贿赂、货物运输代理）按叶律师指示归**飞力达**，因是飞力达公司的合同。（S7）
10. 空白模板 → `其他/模板库`，不进客户文件夹、不进 `其他` 根。（S4）
11. 非合同件、重复件、无归属杂件 → `其他`；`廉洁承诺书（和告知书）` 按 11/18 拍板也归 `其他`（file_rules `__OTHER__`，不再豁免留中转）。（S7/S10）
12. 待定件默认留原地出清单；叶律师说「丢其他」才加 `--fallback`。（S7）
13. 判定六级：主体 → 文件名/文件夹 → 正文关键词（≥3 字）→ 固定规则 → 模板 → 待定。（S5）
14. 弱别名（如「齐心」）只提示，不自动移动。（S5）
15. 硬红线：不删文件、不覆盖、演练默认、归属有歧义问人不猜。（S2）
16. 代码走 GitHub、数据走 iCloud；改完必须 push。（S8）
